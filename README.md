# Ashkenazi population structure reproducibility repository

- `Ashkenazi_Population_Structure_Reassessed_V1_repository/`: the original Version 1 Global25 reproducibility package on `main`.
- `Ashkenazi_Population_Structure_Reassessed_Peer_Review_repository/`: the peer-review reproducibility package integrating the Global25 source-panel sensitivity suite with the AADR Stages 01-08 genotype analysis.
