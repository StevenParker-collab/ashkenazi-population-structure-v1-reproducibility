## Included data

- Global25 source/target rows, raw outputs, grouped outputs, comparison tables, screenshots, scripts, and checksums.
- AADR Stages 01-08 scripts, manifests, QC records, logs, PCA/FST/ADMIXTURE tables, synthesis outputs, formal-stats readiness notes, and figures.
- Final manuscript PDF and source preprint PDFs used for synthesis.

## Excluded data

Multi-gigabyte raw genotype binaries and raw ADMIXTURE matrix directories are not duplicated in GitHub. They are excluded for size and repository hygiene. The package documents the AADR source version and stage scripts needed to rebuild those intermediates.
