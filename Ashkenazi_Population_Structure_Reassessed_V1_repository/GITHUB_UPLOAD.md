# GitHub upload instructions

1. Create a new empty public repository for the Version 1 package.
2. Extract the final ZIP.
3. Upload the contents of the `Ashkenazi_Population_Structure_Reassessed_V1_repository` folder so that `README.md` appears at the repository root.
4. Do not upload the outer ZIP as the only repository file.
5. After upload, run or inspect `python3 verify_repository.py` locally from a downloaded copy.
6. Create a versioned release only after the repository contents match the final ZIP.

This package intentionally contains no Version 4 DOI metadata and no earlier qpAdm analysis.
